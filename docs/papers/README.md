# Papers

Save PDFs of the key reference papers here for offline reading (PDFs themselves are gitignored — this file tracks which ones matter and why).

- Wagner, Dell & Eisenman (2017) — *An Analytical Model of Iceberg Drift* — the Module 2 physics core. https://journals.ametsoc.org/doi/abs/10.1175/JPO-D-16-0262.1 (reference code: https://www.tillwagner.me/wde17)
- *Modeling giant-iceberg drift under the influence of sea ice in the Weddell Sea, Antarctica* — the sea-ice coupling thresholds used in `src/models/iceberg_drift/wagner_model.py`. https://www.cambridge.org/core/journals/journal-of-glaciology/article/modeling-gianticeberg-drift-under-the-influence-of-sea-ice-in-the-weddell-sea-antarctica/814FC678B7F55C698343BF19A4B54CA6
- IDRIFTNET (2025) — physics+ML hybrid drift model, validated on A23a/B22a. Best single implementation reference for the stretch-goal residual net. https://arxiv.org/html/2507.00036
- Antarctic sea ice prediction with a ConvLSTM network — directly comparable architecture for Module 1. https://www.sciencedirect.com/science/article/abs/pii/S1463500324000738
- IceNet, Nature Communications (2021) — broader sea-ice forecasting context. https://www.nature.com/articles/s41467-021-25257-4
- Should Sea-Ice Modeling Tools Designed for Climate Research Be Used for Short-Term Forecasting? — why baselines matter here. https://pmc.ncbi.nlm.nih.gov/articles/PMC7683458/
- Strategies to improve the isochrone algorithm for ship voyage optimisation — Module 3 routing reference. https://www.tandfonline.com/doi/full/10.1080/17445302.2024.2329011
